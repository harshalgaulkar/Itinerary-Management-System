# IMS Backend - Quick API Reference for React Native

## 🚀 Quick Start

**Base URL:** `http://localhost:4000`

### Headers for Authenticated Requests
```javascript
headers: {
  'Content-Type': 'application/json',
  'user_id': userId
}
```

---

## 🔐 Auth Endpoints

### Sign Up
```
POST /users/signup
{
  email, password, full_name, phone
}
```

### Sign In
```
POST /users/signin
{
  email, password
}
→ Returns: {token, user_id, full_name, email, phone, role}
```

---

## 👥 User Endpoints

### Get Profile
```
GET /users/profile/:user_id
Headers: user_id
```

### Update Profile
```
PUT /users/update/:user_id
{full_name, email, phone} (optional fields)
Headers: user_id
```

### Get My Bookings
```
GET /users/bookings/:user_id
Headers: user_id
```

## 👨‍💼 Admin Endpoints

### Create User (First admin = no token needed)
```
POST /admin/signup/user
{
  email, password, full_name, phone, role
}
Headers: user_id (skip for first admin)
```

### Get All Users
```
GET /admin/users
Headers: user_id (admin only)
```

### Update User Role
```
PUT /admin/user/:user_id/role
{role: "user|manager|admin"}
Headers: user_id (admin only)
```

### Delete User
```
DELETE /admin/user/:user_id
Headers: user_id (admin only)
```

## 📊 Response Format

```json

  "status": "success",

}
```

### Error
```json
{
  "status": "error",
  "error": "Error message"
}
```

---

## ⚠️ Common Errors

| Error | Cause | Fix |
|-------|-------|-----|
| `Invalid Email` | Email format wrong | Use valid email |
| `Invalid Password` | Wrong password | Check password |
| `User already exists` | Email taken | Use new email |
| `Unauthorized` | Missing/wrong user_id | Add user_id header |
| `User not found` | Invalid user_id | Check ID |
| `Validation error` | Missing fields | Check all required fields |
| `No seats available` | Package full | Choose different date |
| `Booking not found` | Invalid booking_id | Check ID |

## 🔧 React Native Implementation

```javascript
// Setup
import AsyncStorage from '@react-native-async-storage/async-storage';

const API_BASE_URL = 'http://192.168.1.x:4000'; // Your server IP

// API Call Helper
const apiCall = async (endpoint, method = 'GET', body = null) => {
  try {
    const userId = await AsyncStorage.getItem('user_id');
    const headers = { 'Content-Type': 'application/json' };
    
    if (userId) headers['user_id'] = userId;
    
    const options = { method, headers, timeout: 10000 };
    if (body) options.body = JSON.stringify(body);
    
    const res = await fetch(API_BASE_URL + endpoint, options);
    const data = await res.json();
    
    if (data.status === 'error') throw new Error(data.error);
    return data.data;
  } catch (error) {
    console.error('API Error:', error);
    throw error;
  }
};

// Usage Example
const signIn = async (email, password) => {
  const user = await apiCall('/users/signin', 'POST', { email, password });
  await AsyncStorage.setItem('user_id', user.user_id.toString());
  return user;
};

const getBookings = async () => {
  return apiCall('/bookings?page=1&limit=10');
};

const createBooking = async (booking) => {
  return apiCall('/bookings', 'POST', booking);
};
```

## 🔑 Important Notes

1. **First Admin Bootstrap**: First `/admin/signup/user` doesn't need authentication
2. **Role Values**: `user`, `manager`, `admin` (lowercase)
3. **Payment Methods**: `card`, `upi`, `netbanking`, `cash`, `other`
4. **Booking Status**: `pending`, `confirmed`, `cancelled`, `completed`
5. **Payment Status**: `success`, `failed`, `pending`
6. **Rating Range**: 1-5 stars only
7. **Store Token**: Save user_id in AsyncStorage after login
8. **Auth Header**: Always include `user_id` header for authenticated requests
