## 📞 Quick Reference

### API Base URL
```
http://localhost:4000
```
**Note**: Change `localhost` to your server IP (e.g., 192.168.1.100)

### Common Headers
```javascript
{
  'Content-Type': 'application/json',
  'user_id': '<user_id>'
}
```

### Error Response Format
```json
{
  "status": "error",
  "error": "Error message"
}
```

### Success Response Format
```json
{
  "status": "success",
  "data": { /* response data */ }
}
```

## 🔧 Troubleshooting

### Server not connecting?
- Check: API URL in config
- Check: Server is running
- Check: Firewall allows connection
- See: FRONTEND_DOCUMENTATION_GUIDE.md

### Authentication not working?
- Check: user_id header is being sent
- Check: Credentials are correct
- See: REACT_NATIVE_API_GUIDE.md → Auth
