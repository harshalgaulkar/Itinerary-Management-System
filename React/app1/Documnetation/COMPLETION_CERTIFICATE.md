## 🏗️ Architecture

### Technology Stack
- **Framework**: React Native 0.81.5
- **Platform**: Expo 54.0.32
- **Navigation**: React Navigation 6.x
- **HTTP**: Axios 1.6.2
- **State**: React Context API
- **Storage**: Expo Secure Store + AsyncStorage

### Layer Architecture
```
┌─────────────────────────────┐
│   Presentation Layer        │
│   (Pages & Components)      │
├─────────────────────────────┤
│   State Management Layer    │
│   (AuthContext)             │
├─────────────────────────────┤
│   API Integration Layer     │
│   (Axios + Interceptors)    │
├─────────────────────────────┤
│   Utilities & Helpers       │
│   (Functions & Hooks)       │
├─────────────────────────────┤
│   Backend API               │
│   (IMSBackend)              │
└─────────────────────────────┘
```
