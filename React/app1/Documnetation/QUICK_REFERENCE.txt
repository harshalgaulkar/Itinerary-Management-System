## 🧪 Quick Test Commands

**See all packages with dates:**
```sql
SELECT p.package_id, p.title, COUNT(pd.package_date_id) as dates
FROM packages p LEFT JOIN package_dates pd ON p.package_id = pd.package_id
GROUP BY p.package_id ORDER BY p.package_id;
```

**Check Package 1 dates:**
```sql
SELECT * FROM package_dates WHERE package_id = 1 ORDER BY start_date;
```

**Find available dates for March 2026:**
```sql
SELECT p.title, pd.start_date, pd.end_date, (pd.seats_total - pd.seats_booked) as available
FROM packages p JOIN package_dates pd ON p.package_id = pd.package_id
WHERE MONTH(pd.start_date) = 3 AND YEAR(pd.start_date) = 2026
ORDER BY pd.start_date;
```

## 📞 Troubleshooting

**Q: Packages not showing dates in booking page?**
A: Verify with: `SELECT COUNT(*) FROM package_dates;` (should be 290)

**Q: Need to clear data and re-insert?**
A: Run: `DELETE FROM package_dates;` then re-execute the SQL file

**Q: Want to check a specific package?**
A: Run: `SELECT * FROM package_dates WHERE package_id = XX ORDER BY start_date;`

**Q: Booking still failing?**
A: Check backend logs and verify `package_date_id` exists in the result above
